# LOFT PARK — концепт-сайт ресторана

Портфолио-проект: кинематографичный 3D-сайт ресторана Loft Park (Нальчик, ЦПКиО).
**Не официальный сайт.** Данные (адрес, часы, меню, рейтинг) — из открытых
источников, сентябрь 2026. Фото и логотип ресторана не используются: весь визуал
процедурный — three.js-сцена, canvas-текстуры, SVG и CSS.

Next.js 16 (App Router, static export) · React Three Fiber · drei · postprocessing ·
GSAP ScrollTrigger · Lenis · Motion · Tailwind v4 · Zustand.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # статический сайт в out/
```

## Как устроено

**Одна сцена на всю страницу.** `SceneLayer` держит фиксированный `<Canvas>`,
DOM-секции идут поверх. Камера едет по ключевым кадрам
(`src/components/scene/keyframes.ts`): парк → фасад → зал → три блюда → бар →
DJ → веранда → вид сверху-карта.

**Скролл ↔ камера.** У секций есть атрибут `data-cam="N"`. `lib/scroll.ts`
меряет позиции маркеров и превращает scrollY в непрерывное `cam`: центр
маркера в центре экрана — камера ровно в кадре N. Меняете порядок секций
в `app/page.tsx` — меняйте и `KEYFRAMES`.

| Кадр | Секция | Что в 3D |
|---|---|---|
| 0 | Hero | вход в ночной парк, светлячки, фонари |
| 1 | Аллея | проезд по аллее |
| 2 | Площадь | плитка, 3D-буквы LOFT [лист] PARK, деревья в гирляндах с фонариками |
| 3 | Терраса | маркизы на стальном каркасе, стволы сквозь крышу, плетёные кресла, обогреватели |
| 4–6 | Три кухни | хачапури / карбонара / роллы собираются из ингредиентов |
| 7 | Меню | дрейф к бару |
| 8 | Вечера | DJ-пульт у стены из мха с надписью LOFT PARK |
| 9 | Шатёр | белый шатёр, тюлевые шторы на ветру; в DOM — горизонтальная лента |

Сцена — стилизованная диорама настоящего Loft Park, собранная по фотографиям
гостей как по референсу (сами фото на сайте не используются). План места —
`src/components/scene/layout.ts`: все объекты и кадры камеры берут размеры оттуда.
| 10 | Бронь | подъём над крышей |
| 11 | Футер | карта сверху, маяк над рестораном |

**Фишки:** прелоадер-неон, буквы героя разлетаются по скроллу, лампы качаются
от курсора (пружинный маятник), курсор-фонарик, 3D-наклон карточек меню,
«стол» с летящими каплями, бронь с переворотом карточки → WhatsApp,
статус «открыто» по времени Нальчика, синтезированный звук атмосферы (Web Audio).

**Бронь** без бэкенда: форма собирает текст и открывает
`wa.me/79387014433` — гостю остаётся нажать «Отправить».

## Производительность и доступность

- Режим `low` (узкий экран или ≤4 ядер): меньше деревьев и светлячков.
- `PerformanceMonitor` снижает dpr при просадке FPS.
- `prefers-reduced-motion`: без Lenis, без параллакса и автоанимаций сцены.
- Нет WebGL — тёплый градиент вместо сцены, сайт полностью рабочий.
- `EffectComposer multisampling={0}` — MSAA на Metal/ANGLE даёт чёрный кадр.

Отладка: `?nofx` — сцена без постобработки, `?debug` — `window.__loft`
(state R3F и fx).

`robots: noindex` — концепт не должен конкурировать в поиске с настоящими
страницами ресторана.
